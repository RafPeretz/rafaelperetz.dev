# rafaelperetz.dev

Portfolio site for Rafael Peretz, a freelance DevOps & Cloud engineer. Built with Next.js 16, TypeScript, Tailwind CSS v4 and next-intl (EN / FR / HE).

> Work in progress. Badges, the architecture overview, CI/CD and the custom-domain runbook arrive in Phase 6.

## Getting started

```bash
corepack enable          # or: npm i -g pnpm@10
pnpm install
cp .env.example .env.local
pnpm dev
```
